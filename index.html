EUROLEAGUE PULSE • Arquitectura 100% Estática para GitHub Pages

Automatización 24/7 en GitHub Pages (Sin Servidor)

Recolecta los feeds RSS reales y tradúcelos automáticamente cada 30 minutos usando GitHub Actions

¿Cómo funciona en GitHub Pages gratis?

  1. Sube este archivo index.html a tu repositorio de GitHub y activa GitHub Pages.
  2. Crea los dos archivos siguientes en tu repositorio: scripts/fetch_news.py y .github/workflows/update-news.yml.
  3. Cada 30 minutos, GitHub Actions ejecutará el scraper en Python, detectará rumores vs noticias oficiales, traducirá a ES/EN/TR/EL y guardará data/news.json, data/schedule.json y data/standings.json directamente en tu repo.

2. .github/workflows/update-news.yml 
name: Actualizar Noticias, Calendario y Clasificación Euroliga

on:
  schedule:
    - cron: '*/30 * * * *' # Se ejecuta automáticamente cada 30 minutos
  workflow_dispatch:       # Permite ejecución manual desde la pestaña Actions

permissions:
  contents: write

jobs:
  scrape-and-translate:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repositorio
        uses: actions/checkout@v4

      - name: Configurar Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Instalar dependencias
        run: pip install feedparser deep-translator requests

      - name: Ejecutar scraper multilingüe y datos de competición
        run: |
          mkdir -p data
          python scripts/fetch_news.py

      - name: Guardar cambios en GitHub Pages
        run: |
          git config --local user.email "action@github.com"
          git config --local user.name "EuroLeague Bot"
          git add data/news.json data/schedule.json data/standings.json
          git diff --quiet && git diff --staged --quiet || (git commit -m "chore: actualizar feed, calendario y tabla Euroliga" && git push)
